# Realm Plan 5 — Session shell (one-pass overhaul)

> **For agentic workers:** executed subagent-driven in one pass, one workstream per implementer, sequential on `feat/plan-05-session-shell`. Reviews are batched per workstream pair, mutation-grade where logic changes. The 2026-08-27 UI audit (`docs/superpowers/specs/2026-08-27-ui-audit.md`) and the spec's Amendment 2026-08-27 are the requirements; audit finding ids (U-H1, V-D1, A-M9 …) are the traceability keys.

**Goal:** full-bleed panes with plain dividers replace the inset panels; sessions gain t3code-grade chrome (context row with live git info, editable titles, status); the audit's P0s, keyboard/command layer, multi-agent visibility, and finishing pass all land together.

**Workstreams (order matters):**

- **W1 — Layout: full-bleed + dividers.** Kill gutters/radius/border/shadow on panes; 1px dividers incl. sidebar boundary; delete the global topbar (LayoutMenu → palette + pane ⋯ menu; Breadcrumb deleted); resize handle = the divider itself (hover/active accent). Restyle `.panel`→`.pane` keeping the DOM contract tests rely on (`data-leaf-id`, `data-focused`, PanelBar, drop zones). Tokens: light `raised #f7f7f9`, new `--rl-hover` used for all hover/selected fills (V-D1/D2/D6). Settle animation reviewed for the new composition.
- **W2 — P0 honesty batch.** Profile seeding on boot + sheet affordance (U-H1); WS reconnect: connection state, banner+retry, backoff, `openSession` catch-up (A-H1); delete confirm reusing the space-settings pattern (U-H2); `textFaint` ≥4.5:1 + role demotions (V-T1/A-H4); strip `safe center` + scrollIntoView + hidden scrollbar (A-H2); single overlay slot (U-M4/V-F5); dead Settings gear routed to space settings (U-M9).
- **W3 — Sessions-not-terminals.** Server: `workspace.gitInfo` RPC (git shell-out, 3s cache, null for non-repos) + terminal auto-title from cwd basename (U-M1). Renderer: pane-header per A2 (editable title inline, ⋯ menu w/ split-down/rename/delete, status dot, model chip); composer context row (cwd chip, branch + `+N −M` chip, polls on status transitions/space activation); composer chips row per screenshot; terminal padding/scrollbar/empty hint (V-S3/D4/F3); drafts move to the store keyed by session id (A-M9).
- **W4 — Command & control.** Bindings over existing actions: ⌘1..9 + ⌃⇥ spaces, ⌘⌥arrows pane focus, ⌘W close-pane, ⌘T new terminal, ⌘N new session, ⌘⇧\ split down (U-M2/A-M7); `Menu.tsx` keyboard pass once for all menus + shortcut-hint column + icon check (U-M10/A-H3/V-F6); palette overhaul: all-space items w/ space+recency, duplicate disambiguation (quadrant glyph + space), sections, hover+cursor, "Search…" placeholder, new-session one-shots, rename/pin/split/close/preset entries (U-H5/H6/M5, V-F4/C3); permission keyboard (autofocus, Enter=Allow, ⌘⌫=Deny, ⇧Enter=Always) + strip status badges + palette "pending permission" jump (U-H3/H4); Esc interrupts focused running session (U-L9).
- **W5 — Finishing & identity.** Accent discipline (neutral pane icons/glyphs) + accent-lit focused pane header underline/icon (V-C1/D3/X1); accent caret+selection (X3); bundle JetBrains Mono woff2 (X4); ≤4% per-space ground tint (X5); custom selects + input focus ring (V-F1/C4); micro-interactions + menu/palette/sheet enters as spec §4 amendment (V-C2); transcript rhythm: turn spacing, heading scale, aligned 16px rails, tabular-nums, md-table scroll wrap + img max-width (V-S1/S2/T2/T4, A-M1); status-dot idle neutral (V-C5); radius/icon quantization + hit targets (V-F2/F7/F8); persist flush on pagehide (A-M4); tool output clamp + copy buttons (A-M2/M3); remaining cheap P2s (aria labels, pill logic, empty-space hint, rename-vs-drag, focus-visible ×, bypass confirm, chip sizes/labels).
- **W6 — Verification (coordinator):** full gates, live CDP pass (both modes, splits, git chips against a real repo cwd, keyboard walkthrough), migration re-check, screenshots, follow-ups doc.

**Out of scope:** PR-creation workflow (t3code's branch-per-thread model), browser pane, content search, virtualization, ACP modes/models (all remain roadmap).
