# Realm Plan 6 — Grayscale ink, the prompter, instant sessions (one-pass)

> Executed subagent-driven, one workstream per implementer, sequential on `feat/plan-06-grayscale`. Reviews batched per workstream pair, mutation-grade where logic changes. **The authoritative design spec is `docs/superpowers/specs/2026-08-27-design-language.md`** (synthesized from the user's 49-reference corpus + the make-interfaces-feel-better and emil-design-eng skills) — every visual/motion value comes from there, not from this plan.

**User direction being implemented:** grayscale ink theme (purple retired); Codex-style centered prompter (no border, agent icon + model selector inside, suggested prompts); creating a session never asks questions — "+" is always an instant session and the prompter itself carries agent/model/permission choice until the first message; terminals stop being peers of sessions and become a per-session side panel; seamless CLI-missing install flow + first-run onboarding; Hugeicons stroke-standard; emil-design-eng motion language; fewer borders everywhere.

**Workstreams:**

- **W1 — Ink tokens & border reduction.** Implement design-language §3 + §5 verbatim: new dark/light palettes, `--rl-active`/`--rl-edge`/`--rl-space`/`--r-float`/easing tokens, accent = ink, space colour survives only as `--rl-space` (delete ground tint + accent derivation; `paletteFromColor` keeps signature), semantic status dots (running=success), focus rings/selection/buttons per usage rules, the border-reduction sweep (resting `line-strong` borders die; floating surfaces = `--rl-edge` + `--rl-shadow`; sidebar/strip/pane-header/menu/sheet/banner treatments per §5). Theme tests recomputed (contrast asserted, not hexes, where the doc gives latitude).
- **W2 — The prompter.** §4 verbatim: one component, two states (centered hero at ~38vh with greeting + staggered suggestion grid; docked with matching 680px transcript rails), `min(680px, 100%−48px)` centered, borderless (edge+shadow, ring on focus), context-chip row (fixes the cwd cutoff), control row with agent glyph + ghost model/effort/permission chips opening upward + circular send↔stop morph, the 320ms empty→docked move (one instance), "Thinking…" under-strip while streaming.
- **W3 — Instant sessions.** "+" and ⌘N create a session immediately (last-used agent, else Claude; frontier default model labels per kind in presets) and land in the hero prompter; `NewItemMenu` and the create-flow of `NewSessionSheet` are retired (sheet survives only if some path still needs it — prefer full retirement); the prompter's agent chip switches `agentKind` **until the first message** (new guarded RPC `sessions.setAgent`, server-rejects once events exist), model/permission chips keep working throughout; palette one-shots route through the same path.
- **W4 — Terminal side panel + onboarding.** Sessions own an optional terminal: migration v4 adds `sessions.terminal_item_id`; pane-header toggle opens a right-hand internal split (default 38%, resizable) hosting a terminal created lazily at the session's cwd (hidden from the sidebar item list); ⌘J toggles. CLI-missing flow: when the selected agent's probe fails, the prompter is replaced by an install card (probe reason + the exact install command + "Open in terminal" which opens the side panel with the command **pre-typed, never auto-run**). First-run onboarding: on first boot (no spaces), a single centered sheet — welcome, detected-CLI list with status, pick default agent, create first space — replacing today's bare "Create a space" placeholder.
- **W5 — Iconography & motion.** §6 + §7 verbatim: Hugeicons stroke-standard swap (one file), sizes/colors per §7; easings/durations table implemented (press scale, icon cross-fades w/ blur, menu origin-scale 140ms, sheet 240/160, transcript enter 180ms new-items-only, tool-row grid-rows expand, palette stays instant); the do-NOT-animate list enforced; tool-card collapsed-row + grouped-summary treatment and the permission-card numbered-list redesign (§5) land here with their interactions.
- **W6 — Verification (coordinator):** gates, live CDP pass both modes (hero→docked transition, instant session, agent-switch guard, terminal panel, install card with a fake missing CLI, onboarding on a fresh home), migration re-check, screenshots.

**Out of scope:** browser side panel (roadmap; the terminal panel establishes the pattern), content search, PR workflows, auto-running installers.
