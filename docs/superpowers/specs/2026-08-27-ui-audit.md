# Realm UI Audit — where the app falls short

**Date:** 2026-08-27 · **Basis:** the post-Plan-4 Codex-flat shell on `main` (`b17e874`). Three parallel audits — visual design (V), interaction/IA (U), states/accessibility/motion (A) — over 12 screenshots of real user data plus full source reads. Pixel values sampled, keyboard inventory grepped, journeys traced through code. This document seeds the next design plans.

**Overall read:** the shell now has a coherent flat language and sound structure; the shortfalls cluster into (1) a handful of genuinely broken paths, (2) a missing keyboard/command layer, (3) state-feedback gaps that undermine the multi-agent promise, and (4) finishing details that separate "competently flat" from "designed".

---

## P0 — Broken or blocking (fix first, small plan)

1. **First-run is a dead end.** [U-H1] Fresh install: `NewSpaceSheet` requires a profile; none exists, none can be created (the `profiles.create` RPC has zero renderer callers), Create stays disabled with no message. **Fix:** seed a default profile on first boot server-side + inline "new profile" affordance in the sheet.
2. **WS disconnect bricks the app silently.** [A-H1] `rpc/client.ts` closes permanently; no reconnect, no banner; status dots keep pulsing "running" forever. `lastSeq` resume machinery already exists. **Fix:** connection state in the store, disconnected banner + retry, backoff reconnect + event catch-up.
3. **Delete destroys transcripts with no confirmation.** [U-H2] Context menu "Delete" is one row below "Close", irreversible, unconfirmed. Space deletion already has an inline confirm — reuse the pattern.
4. **Light mode's ladder collapses.** [V-D1] `raised == panel == #ffffff`: user bubbles are literally invisible (sampled), inline code vanishes, every raised-hover does nothing. **Fix:** light `raised: #f7f7f9` + a dedicated `--rl-hover` token (also fixes dark's Δ7 near-invisible step [V-D2] and menus highlighting *downward* [V-D6]).
5. **`textFaint` fails contrast on load-bearing text.** [V-T1, A-H4] ~2.6:1 on group labels, palette hints, `INPUT`/`RESULT`, the composer's only "⌘↵ to send" hint. **Fix:** raise faint to ≥4.5:1 (~`#7a7b86` dark / `#83838f` light) or demote those roles to `textDim`.
6. **Space strip clips left spaces at 10+.** [A-H2] `justify-content: center` + `overflow-x: auto` = leftmost spaces unreachable. **Fix:** `justify-content: safe center`, hide scrollbar, `scrollIntoView` on active.
7. **Sheets and the palette stack.** [U-M4, V-F5] Independent store fields; palette opens over a live sheet, double backdrop, two focus traps (3 of 12 audit screenshots were contaminated by this). **Fix:** one overlay slot — opening either closes the other.

## P1 — The next design plan's spine

**Multi-agent visibility & control** (the core promise, currently under-delivered):
- Cross-space status: a session finishing / erroring / waiting-for-permission in a hidden space is invisible; `sessionStatus` already holds the data. Badge the space strip; consider a topbar "1 waiting" pill. [U-H3]
- Permission cards are mouse-only; the hottest interaction has no keyboard, no autofocus, no cross-pane queue. Enter=Allow, an explicit deny key, and a palette "respond to pending…" jump. [U-H4]
- Interrupt: Stop is one icon-only button inside the owning pane's composer; no Esc-to-interrupt, nothing in sidebar/palette. [U-L9]
- Error routing is split-brain: transcript errors inline, store errors in one global overwriting bar that clears on space switch; agent-login recovery text says "run codex login in a terminal" without offering one. [U-M6, A-M11]

**The keyboard & command layer** (the app has ⌘K, ⌘\, ⌘↵ — nothing else):
- Bindings over existing store actions: spaces (⌘1..9 / ⌃⇥ — `nextSpace` exists and is trackpad-only today), pane focus (⌘⌥arrows), ⌘W close, ⌘T/⌘N new, ⌘⇧\ split down (store supports "col"; no binding, no UI). [U-M2, A-M7]
- `Menu.tsx` keyboard support once fixes five surfaces: focus-in on open, arrow nav, focus restore, correct checked roles, shortcut-hint column. [U-M10, A-H3]
- Palette overhaul: search all spaces (today: active space only), sort by recency, disambiguate duplicates ("Open Terminal" ×4 [V-F4]), group sections, hover feedback + cursor, honest placeholder ("Ask or search…" can do neither [U-H6]), entries for session-creation/split/rename/pin. [U-H5, V-C3]
- New-session flow: probe cached (store already holds it), last-used defaults, one-shot palette entries per agent. [U-M5]

**Accent discipline + the identity move:**
- Accent leaks (every panel icon, every sidebar glyph) get pulled back; reinvest in the **accent-lit focused panel** — focused border + icon take the space colour, telling you *where you are* and *whose space you're in* in one glance. [V-C1, V-D3, V-X1]
- Companion identity moves, all cheap: accent caret + selection [V-X3]; the quadrant glyph as a recurring mark (sharpen, reuse in palette/layout menu) [V-X2]; bundle a mono face (biggest remaining "generic" tell) [V-X4]; the spec's ≤4% ground-tint escape hatch, per space [V-X5].

**Surface polish with structural value:**
- Custom-style all selects (`appearance:none` + own chevron) and the input focus ring formula — the two highest-touch surfaces expose raw Chromium controls today. [V-F1, V-C4]
- Micro-interaction pass: 100ms hover transitions, `:active` scale, drop-zone opacity ease, menu/palette/sheet enter (spec §4 amendment — deliberate, not drive-by). [V-C2, A-motion]
- Transcript rhythm: cluster-then-breathe turn spacing, real heading scale, aligned left rails, tabular numerals on live metrics. [V-S1, V-T2, V-S2, V-T4]
- Markdown table overflow scrolls the whole transcript; images lack max-width. [A-M1]

## P2 — Robustness & finishing (batchable follow-ups)

- Composer drafts to the store (survive layout changes; bystander pane remounts also replay the settle animation and re-fit terminals — same root cause). [A-M9, A-M10]
- Persist flush on `pagehide` (resize within 300ms of quit is lost). [A-M4]
- Tool output: clamp giant results with an expander; copy buttons on wells. [A-M2, A-M3]
- Terminals: auto-title from cwd/process (every terminal is "Terminal" forever [U-M1]); interior padding; xterm scrollbar theming; empty-terminal hint overlay. [V-S3, V-D4, V-F3]
- Timestamps/recency: nothing in the UI shows when anything happened; sidebar relative times, palette recency sort. [U-H5]
- Status dot semantics: green "idle" reads as a verdict; idle should be neutral. [V-C5]
- Presets: fill from open items first; consider one-step layout undo. [U-M8]
- Sidebar: rename-vs-drag conflict [A-M5]; focus-visible on the hover-only × [A-M8]; OPEN ordering churn vs spatial memory [U-L6]; empty-space hint [A-L6]; pinned-grid rethink (tiles vanish when opened — feels broken; consider Arc-style persistent tiles) [U-L5].
- A11y: transcript live-region announces every streaming delta (VoiceOver-hostile) while real status changes go unannounced [A-M6]; aria labels on palette input and row status [A-L3, A-L4]; reduced-motion leaves a frozen spinner glyph [A-L5].
- Details: radius system is 7 values pretending to be 3 [V-F2]; icon sizes quantized + stroke scaling [V-F7]; hit-target extension on small buttons [V-F8]; menu ✓ as a font glyph amid an icon set [V-F6]; dead Settings gear [U-M9]; breadcrumb duplicates the panel bar and is inert [U-L4]; chips at 10.5px [V-T5]; model/effort chips read as raw ids, defaults unexplained [U-L2]; cost tooltip/rollup [U-L3]; panel title 12px vs spec 13 [V-T3]; `bypassPermissions` one-click with styling as the only signal [U-M7]; light backdrop grey-out [V-D5]; light primary-button contrast at accent clamp edge [A-L8]; zoom-out traffic-light overlap [A-L7]; empty-title text-balance [V-T6]; new-messages pill false positives [A-L2]; permission-card empty-field fallbacks [A-L1]; swipe position cue distance [U-L10]; ⌘↵-vs-Enter teaching [U-L7].

## Suggested slicing

- **Plan 5a — "Make it honest":** P0 items 1–7. Small, mostly one-liners to one-filers; ships in a day.
- **Plan 5b — "Command & control":** the keyboard/command layer + multi-agent visibility block. This is the plan that changes what the app *is* for its target user.
- **Plan 5c — "The finishing pass":** accent discipline + identity moves + surface polish + transcript rhythm.
- P2 items ride along in whichever plan touches their files.
